## 1️⃣ Philosophy of Vim

Vim is **not a text editor** in the traditional sense.  
It is a **language for manipulating text**.

Key ideas:

- You describe _what_ to edit, not _how_
    
- Editing is faster than thinking
    
- The keyboard is the primary interface
    

> "Vim rewards thinking in motions and transformations, not keystrokes."

---

## 2️⃣ Vim Mental Model

### Vim Grammar

```
[count] + operator + motion = edit
```

Examples:

- `dw` → delete word
    
- `3j` → move down 3 lines
    
- `ci(` → change inside parentheses
    

This composability is Vim's true power.

---

## 3️⃣ Modes in Depth

|Mode|Purpose|
|---|---|
|Normal|Navigation + commands|
|Insert|Text input|
|Visual|Selection|
|Command|Ex commands|
|Replace|Overwrite mode|
|Terminal|Embedded shell|

Mode switching is deliberate—**not accidental**.

## 4️⃣ Motions, Operators & Text Objects

### Motions

- `w`, `b`, `e` → words
    
- `f<char>`, `t<char>` → inline jumps
    
- `%` → matching pairs
    

### Operators

- `d` delete
    
- `y` yank
    
- `c` change
    
- `>` `<` indent
    

### Text Objects

- `iw`, `aw`
    
- `i(` `i{}` `i"`
    

Example:

```vim
ci"
di(
yap
```

## 5️⃣ Counts & Composability

Everything is repeatable:

```vim

```

Vim scales with file size effortlessly.

## 6️⃣ Undo Tree & Time Travel

Vim has a **non‑linear undo tree**.

Key commands:

- `u` undo
    
- `<C-r>` redo
    
- `:undolist`
    

Persist undo history:

```vim
set undofile
set undodir=~/.vim/undo
```

---

## 7️⃣ Insert Mode Power

- `<C-n>` / `<C-p>` → completion
    
- `<C-r>0` → paste register
    
- `<C-o>` → single normal command
    

Avoid staying in insert mode.

## 🔟 Search, Replace & Regex



